# viaggio-ai

## Development Environment Setup

Follow these steps to get the Viaggio.ai app running locally.

### Prerequisites

- **Node.js** v18.x (use [nvm](https://github.com/nvm-sh/nvm) to manage versions)  
- **Python** 3.10+ (use `pyenv` or your system’s package manager)  
- **PostgreSQL** 14+ (or any compatible Postgres)  
- **Git** (to clone the repo)  
- An `.env` file (see below)

git clone https://github.com/<your-org>/viaggio-ai.git
